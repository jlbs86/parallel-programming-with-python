# Building the Documentation

This project's API documentation is generated with
[Sphinx](https://www.sphinx-doc.org/) directly from the Sphinx-style
(reStructuredText field list) docstrings in every example module.

## Setup

```bash
pip install -r docs/requirements.txt
```

## Build

```bash
python -m sphinx -b html docs/source docs/build
```

Open `docs/build/index.html` in a browser to view the generated site.

## Structure

- `docs/source/conf.py` -- Sphinx configuration (autodoc, napoleon,
  intersphinx, the Read the Docs theme).
- `docs/source/index.rst` -- documentation home page and table of contents.
- `docs/source/theory.rst` -- conceptual overview of the four parallelism
  models covered by this repository.
- `docs/source/algorithms.rst` -- API reference for every `mpi4py`
  algorithm example (autogenerated from docstrings).
- `docs/source/shared_memory.rst`, `gpu.rst`, `recommender.rst`,
  `testing.rst` -- API reference and guides for the remaining sections.
