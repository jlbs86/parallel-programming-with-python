Parallel Programming with Python
=================================

A hands-on, example-driven course repository covering distributed-memory
parallelism (``mpi4py``), shared-memory parallelism (multiprocessing,
threading, and Numba/OpenMP-equivalent kernels), GPU parallelism (CUDA via
``numba.cuda``), and a real parallel recommender system.
